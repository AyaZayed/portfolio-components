# Aya Zayed portfolio: React + Tailwind v4 components

Drop these files into a Vite + React + Tailwind v4 project (Figma Make's default setup).

- `App.tsx` composes the page; `components/` has one file per section.
- All content lives in `data.ts`, so edit text and projects there.
- `styles/theme.css` has the colour tokens (lighter beige, plus automatic dark mode). Use classes like `bg-bg`, `text-accent`, `border-line`.
- `assets/` has the hero video, hero poster and project screenshots.
